# 지식창고 문서 연결

`/knowledge`의 기존 문서함에 문서 연결·백링크·그래프를 추가했습니다. ARGO 소스의 복사나 의존 없이 위키링크 방식을 별도로 구현했습니다.

- 본문에 `[[문서 제목]]` 또는 `[[문서 제목|표시 이름]]`을 입력합니다. 제목은 공백·대소문자·유니코드 조합을 정규화해 비교하며, 같은 제목이 여러 개면 연결하지 않고 안내합니다.
- 문서를 연 뒤 **문서 링크 넣기**에서 대상을 선택하면 `[[문서 ID|표시 이름]]`이 본문에 들어갑니다. 제목을 바꿔도 대상 ID로 연결됩니다. 수동으로 입력한 제목 링크는 제목 변경 시 수정해야 합니다.
- 문서 연결 영역에서 나가는 링크와 백링크를 누르면 해당 문서가 열립니다. 편집기의 원문은 그대로 편집할 수 있습니다.
- **연결 그래프**에서 문서를 클릭하거나 키보드 Enter·Space로 엽니다. 검색, 선택 문서 주변 보기, 확대·축소, 스크롤, 문서 목록 보기를 제공합니다. 최대 80개를 표시하며 더 많으면 검색으로 좁히도록 안내합니다.
- 저장 전 편집 내용도 현재 화면의 그래프에 반영됩니다. 실제 저장은 기존 자동 저장·충돌 처리 경로를 사용합니다. 휴지통 문서는 그래프에서 제외하고 복원 시 다시 계산합니다.

## 저장과 접근

기존 `knowledge_documents.body_text`를 읽어 관계를 메모리에서 계산합니다. DB 마이그레이션·관계 테이블·모델 호출은 추가하지 않습니다. 기존 `/api/knowledge/workspace`의 로그인·활성 직원 검사와 Supabase RLS로 반환된 문서만 처리하며, 추가 API나 관리자 키를 사용하지 않습니다. 그래프 필터는 접근 제어가 아닙니다.

이 기능은 문서 탐색 기능입니다. 자동 AI 기억 정리, 의미 유사도 연결, 질문 기반 검색·GraphRAG는 포함하지 않습니다. 기존 지식창고의 Supabase 환경변수·테이블·직원 초대 설정이 먼저 필요합니다(`supabase/knowledge-setup.md`).

## 확인

Node 24 이상에서 `node --test scripts/knowledge-links.test.mjs`. 제목 중복, 삭제·복원, 백링크 중복 제거, ID 링크의 제목 변경 내성, 이스케이프와 유니코드 정규화를 확인합니다. 운영 계정·데이터에 대한 쓰기 테스트는 수행하지 않습니다.

2026-11-15 로컬 브라우저에서 실제 컴포넌트와 임시 예시 문서로 링크 삽입, 그래프 클릭, 백링크 이동, 검색 결과 없음, 확대·초기화, 모바일 터치, Enter 키로 문서 열기를 확인했습니다. 1280px 화면과 390px 화면을 확인했고, 모바일 페이지 전체 폭은 390px로 유지되며 큰 그래프만 내부 스크롤됩니다. 좁은 화면에서 선택 노드가 보이도록 그래프를 자동으로 가운데 맞춥니다. 편집기의 StarterKit에 이미 포함된 Link 확장을 끄고 명시적 Link 설정만 사용해 중복 확장 경고를 없앴습니다.

이때 로컬에는 `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`가 없어 실제 `/knowledge`는 설정 안내를 표시했습니다. 직원 로그인·DB 저장·다른 기기 동기화는 검증하지 않았습니다. 임시 브라우저 검증 라우트는 작업 후 제거하며 운영 배포에 포함하지 않습니다.
