# 팀 공용 화면 설정

홈 카드(표시·순서·너비)와 사이드바 메뉴(숨김·순서) 설정을 **모든 팀원이 같이 보도록** 서버에 저장합니다. 헤더의 "화면 설정"이나 홈의 "화면 편집"에서 바꿉니다.

## 어디에 저장되나
- Supabase **Storage**의 비공개 버킷 `core-sales-config` 안에 `workspace-config.json` 파일 하나로 저장합니다. **테이블이나 SQL이 필요 없습니다.**
- 이 인트라넷 서버가 이미 가진 `SUPABASE_URL`, `SUPABASE_SECRET_KEY`(서버 전용 키)로 읽고 씁니다. 이 키는 Storage 접근 정책을 우회하므로 서버에서만 쓰고 브라우저로 내보내지 않습니다. 버킷은 처음 저장할 때 자동으로 만들어집니다.
- 이 브라우저에도 사본(localStorage)을 둡니다. 서버를 못 쓰는 동안과 첫 화면을 빨리 그리기 위함입니다.

## 동작 규칙
- 로그인한 사람만 읽고 씁니다(로그인 쿠키 때문에 API 주소가 `/api/leads/workspace-config` 입니다).
- 저장할 때 읽어 온 `version`을 함께 보냅니다. 그 사이 다른 사람이 먼저 저장했으면 서버가 409로 거절하고, 화면이 **최신 설정 위에 내 변경을 다시 적용**해서 두 사람의 변경이 모두 남습니다.
- 다른 사람의 변경은 창으로 돌아올 때, 1분마다, 로그인 직후에 다시 불러옵니다.
- 페이지를 떠나거나 새로고침하는 순간에도 마지막 변경이 저장되도록 바로 보냅니다.
- 저장되는 모양은 서버가 다시 검증합니다(모르는 카드는 버리고, 대시보드 메뉴는 숨길 수 없고, 빠진 카드는 기본값으로 채움).
- 서버 저장소를 쓸 수 없으면 화면 설정 창이 "이 브라우저에만 적용됩니다"라고 알려 주고 이 브라우저에서만 동작합니다.
- "끄기"는 숨기기입니다. 주소를 직접 열면 화면은 열립니다.

## 알아 둘 점
- 한 사람이 바꾸면 모두에게 적용됩니다. 설정 창 맨 위에 "팀 공용 설정 · 저장됨 (마지막 수정 ○○)"이 보입니다.
- 파일 하나라서 변경 이력은 남지 않습니다(마지막 저장 시각·수정자만). 이력이 필요하면 테이블로 옮기는 것이 맞습니다.
- 저장은 "읽고 → 버전 확인 → 덮어쓰기" 순서라, 정말 같은 순간에 저장하면 한쪽이 덮일 수 있습니다. 설정은 가끔 바꾸는 값이라 허용했습니다.
- 개발·테스트에서는 환경변수 `WORKSPACE_CONFIG_FILE`(파일 경로)로 Supabase 없이 저장할 수 있습니다(운영에서는 무시됩니다).
