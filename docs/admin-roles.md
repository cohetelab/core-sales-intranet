# 관리자 구분

팀 공용 화면 설정과 다른 사람의 월 목표는 **관리자만** 바꿀 수 있습니다. 일반 영업은 **본인 월 목표만** 바꿉니다.

## 누가 무엇을 할 수 있나
| | 관리자 | 일반 영업 |
|---|---|---|
| 홈 카드·사이드바 메뉴·데이터 범위(기준일) 변경, 기본값으로 되돌리기 | 가능 | 불가(설정 창이 읽기 전용) |
| 본인 월 목표 | 가능 | 가능 |
| 다른 사람의 월 목표 | 가능 | 불가 |
| 리드 배정·종료·계약 전환·리터치 풀 배정, 상담 기록 | 가능 | 가능(기존과 같음) |

서버가 저장할 때 검사합니다(브라우저 화면만 막는 것이 아닙니다). 일반 영업이 본인 목표 밖의 것을 바꾸려 하면 `403 admin_only`로 거절되고, 화면은 서버에 저장된 설정으로 되돌아갑니다.

## 관리자는 누구인가
- 기본값: **김세현(Connor)**
- 바꾸려면 Vercel 환경변수 `LEADS_ADMINS`에 이름을 쉼표로 적습니다. 예: `김세현(Connor),이익재(Ian)`. 이름은 `lib/sales-reps.ts`의 영업 이름과 같아야 합니다.

## 관리자 비밀번호 (꼭 설정하세요)
로그인이 "이름 고르기 + 공용 비밀번호"라서, **관리자 비밀번호를 따로 두지 않으면 공용 비밀번호를 아는 누구나 관리자 이름을 골라 관리자가 될 수 있습니다.**

1. Vercel 프로젝트 환경변수에 `LEADS_ADMIN_PASSCODE`를 추가합니다(값은 직접 정해서 입력하세요. 이 값은 채팅이나 저장소에 적지 않습니다).
2. 다시 배포합니다.
3. 그 뒤로 관리자 이름은 **관리자 비밀번호로만** 들어갑니다(공용 비밀번호는 거절). 일반 영업은 공용 비밀번호를 그대로 씁니다.
4. 로그인 화면에서 관리자 이름을 고르면 "관리자 비밀번호"로 안내가 바뀝니다.

- 이미 로그인해 있던 관리자 세션은 이 변경 후 다시 로그인해야 관리자로 인정됩니다(관리자 표시가 서명에 들어가기 때문).
- 관리자 비밀번호를 바꾸면 관리자 세션만 무효가 됩니다(일반 영업은 그대로).
- 환경변수를 설정하지 않은 동안에는 관리자 이름도 공용 비밀번호로 들어가고, 관리자 이름이기만 하면 관리자입니다(보호 없음).

## 한계
- 영업이 두 명이라 "관리자 = 대표 1명" 구성입니다. 더 세분화된 역할(예: 팀장)은 없습니다.
- 관리자 여부는 로그인한 이름 기준입니다. 같은 비밀번호를 여러 사람이 공유하면 구분되지 않습니다.
- 리드 배정·종료·계약 전환 같은 영업 업무는 일반 영업도 할 수 있습니다(기존과 같음).
