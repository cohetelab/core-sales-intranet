## 1. 히어로 (첫 화면)

**헤드라인**

> 리드는 시트에 쌓이는데, 누가 연락했는지는 아무도 모릅니다.

**서브 문구**

> 지금 쓰시는 구글 시트를 그대로 두세요. 담당자 배정, 상담 기록, 단계 관리를 그 위에 얹으면, 어떤 리드가 방치됐는지 한눈에 보입니다. 시트가 계속 원본입니다.

**버튼**

- 주 버튼: `무료 시연 신청`
- 보조 링크: `어떻게 동작하나요 ↓`

**보조 문구(버튼 아래, 작게)**

> 초기 연결은 `[저희가 해 드립니다 / 직접 설정 — 결정 필요]`

**히어로 이미지**

- 리드 화면 스크린샷: 상단 요약 카드 4개(전체 고객, 담당자 미배정, 최근 7일 신규, 리터치 예정), 단계 칩, 리드 표.
- 개인정보(이름, 연락처)는 반드시 가린 샘플 데이터를 쓴다.

## 2. 문제 공감

**섹션 제목**

> 이런 일, 한 번쯤 있으셨죠

세 가지만 쓴다. 각각 한 줄 상황 + 한 줄 결과.

1. **새 문의가 들어와도 담당이 정해지지 않습니다.**
   시트에 행은 늘어나는데, 누가 맡았는지는 단체 채팅에서 물어봐야 압니다.
2. **상담 내용이 사람마다 다른 곳에 적혀 있습니다.**
   담당이 바뀌면 지난 통화 내용을 처음부터 다시 물어보게 됩니다.
3. **후속 연락 날짜를 놓칩니다.**
   "다음 주에 다시 연락드리겠습니다"가 시트 어디에도 남지 않습니다.

**섹션 제목**

> 시트는 그대로, 위에 화면만 얹습니다

| 단계 | 제목 | 설명 |
|---|---|---|
| 1 | 시트를 연결합니다 | 지금 쓰시는 구글 시트를 연결합니다. 시트의 구조를 바꾸지 않아도 됩니다. |
| 2 | 리드가 자동으로 보입니다 | 시트에 새 행이 들어오면 약 30초 안에 화면에 나타납니다. 메타 리드 폼이 시트로 들어오는 방식 그대로입니다. |
| 3 | 배정하고 기록합니다 | 담당 배정, 상담 기록, 단계 이동을 하면 같은 시트에 바로 기록됩니다. 시트에서 직접 고쳐도 화면에 반영됩니다. |

## 4. 핵심 기능 (4개)

각 기능은 **제목 + 한 문장 + 화면 이미지 1장**으로 구성한다.

### 4-1. 담당자 자동 배분

> 미배정 리드를 지금 맡은 건수가 적은 영업부터 번갈아 배정합니다. 버튼 한 번이면 끝나고, 담당 칸에서 언제든 바꿀 수 있습니다.

### 4-2. 파이프라인 드래그 이동

> 카드를 리드 → 상담 → 제안 → 계약으로 끌어서 옮기면, 시트의 `단계` 칸에 그대로 적힙니다. 저장됐는지도 화면에서 바로 확인됩니다.

### 4-3. 상담 기록과 일정관리

> 통화 내용은 [날짜 시간 이름]과 함께 이어서 쌓입니다. 리터치 일정이 있는 고객만 날짜순으로 모아 보고, 지난 일정은 빨갛게 표시됩니다.

### 4-4. 한눈에 보는 현황

> 전체 고객, 미배정, 최근 7일 신규, 리터치 예정을 맨 위 카드로 보여 줍니다. 계약 고객과 계약 금액 합계는 고객관리 화면에서 확인합니다.

## 5. 시트를 지키는 안전장치

**섹션 제목**

> 시트를 맡기는 일이라, 덮어쓰기부터 막았습니다

세 가지만 쓴다. 모두 현재 구현된 동작이다.

- **다른 사람이 먼저 고친 칸은 덮어쓰지 않습니다.** 충돌이 나면 저장하지 않고 알려 드립니다.
- **수식이 들어 있는 칸은 건드리지 않습니다.** 인트라넷이 쓰는 칸은 정해진 칸으로 제한됩니다.
- **바꾼 내용은 `인트라넷_기록` 탭에 남습니다.** 누가, 언제, 무엇을 바꿨는지 시트에서 확인할 수 있습니다.

> ⚠ 게시 전 확인: 위 동작은 모의 환경에서 검증했고, 실제 구글 시트에서의 쓰기는 사내 시트로 확인한 뒤에 문구를 확정한다.

## 6. 이런 팀에 맞습니다

**섹션 제목**

> 이런 팀이라면 바로 쓰실 수 있습니다

- 메타 리드 광고 문의를 구글 시트로 받고 있는 팀
- 영업 담당이 2명 이상이라 "누가 맡았는지"가 헷갈리는 팀
- CRM을 도입하기엔 부담스럽고, 시트를 계속 쓰고 싶은 팀

**맞지 않는 경우(솔직하게 적는다)**

- 리드가 하루 몇 건 이하라 시트만으로 충분한 경우
- 구글 시트가 아닌 다른 도구가 이미 원본인 경우

## 7. 자주 묻는 질문

**Q. 시트 구조를 바꿔야 하나요?**
A. 바꾸지 않습니다. 다만 `단계`, `담당자`, `리터치 일정` 같은 칸이 필요합니다. `[칸이 없으면 저희가 추가해 드립니다 — 결정 필요]`

**Q. 시트에서 직접 고치면 어떻게 되나요?**
A. 약 30초 안에 화면에 반영됩니다. 시트가 항상 원본입니다.

**Q. 두 사람이 동시에 같은 고객을 고치면요?**
A. 먼저 저장한 내용이 우선이고, 늦게 저장하려는 쪽에는 충돌 안내가 뜹니다. 덮어쓰지 않습니다.

**Q. 개인정보는 어디에 저장되나요?**
A. `[실제 저장 방식 확정 후 작성 — 현재 구조에서는 시트가 원본이고 별도 DB에 리드를 복제하지 않는다. 서비스화 시 달라질 수 있으므로 게시 전 재확인]`

**Q. 휴대폰에서도 쓸 수 있나요?**
A. 화면은 휴대폰 폭에도 맞춰집니다. 다만 `[모바일 화면 정리 작업 후 문구 확정]`

**Q. 가격은 얼마인가요?**
A. `[가격 결정 필요 — 시연 신청 시 안내 / 월 정액 / 사용자당 중 택일]`

## 10. 검증 지표 (이 페이지로 무엇을 알아낼지)

| 지표 | 보는 이유 |
|---|---|
| 방문 → 시연 신청 전환율 | 문제 공감이 되는지 |
| 신청자의 "리드 받는 방법" 분포 | 메타 리드 폼 대상이 맞는지 |
| 신청자의 영업 인원 분포 | 어느 규모의 팀이 반응하는지 |
| "가장 불편한 점" 자유 입력 | 우리가 놓친 문제, 실제 쓰는 표현 |
| 가격 질문 비율 | 구매 의향의 신호 |

> 성공 기준은 게시 전에 먼저 정한다. 예: `[2주 동안 방문 N명 중 신청 M건 — 숫자 직접 결정]`. 기준 없이 시작하면 결과를 어떻게 해석해도 맞는 것처럼 보인다.
