# 로컬 DeepSeek 주간 보고 파일럿

이 기능은 현재 PC에서만 작동합니다. 인트라넷의 고객사 정보는 브라우저에서 `127.0.0.1`의 연결 서비스로 전달되고, 모델 생성은 LM Studio에서 처리됩니다. 연결 서비스는 보고 초안만 반환하며 고객사 기록을 수정하지 않습니다.

## 시작

1. LM Studio에서 `deepseek/deepseek-r1-distill-qwen-7b` 모델을 로드합니다. 이 PC에는 4비트 GGUF 모델이 설치되어 있습니다. CLI에서는 `lms load deepseek/deepseek-r1-distill-qwen-7b --identifier deepseek-weekly`를 사용합니다.
2. LM Studio의 로컬 서버가 `127.0.0.1:1234`에서 실행되는지 확인합니다. 필요하면 `lms server start --bind 127.0.0.1 --port 1234`를 실행합니다. LM Studio의 CORS와 LAN 공개 옵션은 켤 필요가 없습니다.
3. 이 프로젝트에서 `npm run deepseek:bridge`를 실행합니다. 터미널에 표시되는 일회용 **연결 코드**를 복사합니다. 연결 서비스는 `127.0.0.1:4743`에만 바인딩되며, 종료하면 코드가 무효화됩니다.
4. 개발 중에는 `npm run dev`로 앱을 실행하고 `http://localhost:3000/agents/routines`에서 코드를 입력한 뒤 **연결 확인**을 누릅니다. 이 변경을 Vercel에 배포한 후에는 `https://core-sales-intranet.vercel.app/agents/routines`에서도 같은 PC의 연결 서비스를 사용할 수 있습니다. 브라우저가 로컬 네트워크 접근을 요청하면 허용합니다. 기존 화면 설정에서 루틴을 숨겼다면 화면 설정에서 다시 표시합니다.
5. **주간 영업 보고 초안** 루틴을 새로 실행한 뒤, 실행 결과의 **DeepSeek로 초안 작성**을 누릅니다. 이전 실행 기록에는 활동 원문이 없을 수 있으므로 새 실행이 필요합니다.

## 검토

보고 문장은 고객사 활동 기록에서 일치하는 원문이 있는 경우에만 본문에 표시됩니다. 원문을 찾을 수 없는 모델 출력은 **근거 확인 필요**로 이동합니다. 모든 결과는 원본 고객사 링크를 열어 확인한 뒤 **검토 완료** 또는 **수정 필요**로 표시합니다. 모델이 꺼져 있어도 기존 규칙 기반 루틴은 계속 사용할 수 있습니다.

연결 코드는 브라우저에 저장하지 않습니다. 보고 초안과 검토 기록은 현재 브라우저의 저장소에만 남습니다. 연결 서비스는 배포된 인트라넷 주소와 로컬 개발 주소만 허용하고 별도 연결 코드를 요구합니다.

현재 AI 초안은 원문 발췌를 요약·우선순위·다음 액션으로 분류하는 방식입니다. 모델이 작성한 새 문장을 그대로 채택하지 않으며, 분류의 적절성은 사람이 검토해야 합니다. 주간 보고는 실행 시점까지 최근 7일의 기록을 대상으로 하고 미래·잘못된 날짜의 기록은 제외합니다.

모델 문맥에 맞춰 최대 30개 고객사, 고객사별 최대 10개 근거를 제한된 문자 예산 안에서 전달합니다. 문자 예산은 정확한 토큰 계산이 아니므로 모든 입력의 수용을 보장하지 않습니다. 화면에 전체/참고 건수를 표시하며 일부 원문이 생략·축약되면 경고합니다. 4K 문맥에서는 적은 수의 고객사만 포함될 수 있습니다.

생성은 한 번에 하나씩 실행하며 최대 3분 후 종료됩니다. **작성 중지**로 취소할 수 있고 오류·취소 시 이전 초안은 유지됩니다. 재작성에 성공하면 기존 검토를 대기 상태로 돌립니다. 모델 출력이 잘리거나 JSON 형식이 맞지 않으면 실패로 처리합니다. 저장 이력이 손상되면 원본을 덮어쓰지 않고 **원본 이력 내려받기**를 제공합니다. 이 상태의 새 실행은 메모리에만 유지됩니다.

LM Studio의 JSON Schema 응답 방식은 [공식 structured output 문서](https://github.com/lmstudio-ai/docs/blob/main/1_developer/3_openai-compat/structured-output.md)를 기준으로 구현했습니다.

## 로컬 검증 (2026-11-24)

`deepseek-weekly` 모델의 로드된 문맥 4,096에서 가상 고객사 1곳으로 브라우저 연결과 초안 생성을 확인했습니다. 실제 고객사 데이터를 바꾸거나 외부 모델 API를 호출하지 않았습니다. 이 문서는 로컬 검증 상태이며 운영 배포 완료를 의미하지 않습니다.

주간 보고·후속 연락·마감 점검 실행, 검토 메모와 승인 상태의 새로고침 유지, 잘못된 연결 코드, 생성 취소 시 기존 초안 유지, 손상 이력의 원본 다운로드를 브라우저에서 확인했습니다. 390px 모바일 화면에서 가로 넘침이 없었으며 테스트 후 기존 브라우저 저장값을 복원했습니다. 단위 테스트 16개 묶음과 타입 검사, 변경 파일 린트, 운영 빌드가 통과했습니다.
