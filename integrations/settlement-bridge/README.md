# 정산 시트 브리지 (읽기 전용)

인트라넷의 **정산 시트** 메뉴가 구글 정산 시트를 읽을 때 쓰는 Apps Script 웹 앱입니다. 시트에 **쓰는 동작은 없습니다**(읽기만).

## 왜 필요한가
- 시트 링크 공유를 "제한됨"으로 바꿔도 읽을 수 있습니다(이 스크립트를 배포한 구글 계정이 시트에 접근할 수 있으면 됩니다).
- 정산 시트에는 인플루언서별 지급액과 광고주 계약 매출이 들어 있습니다. 링크 공개로 두지 마세요.

## 설정 순서
1. https://script.google.com 에서 **새 프로젝트**를 만듭니다(이름 예: `정산 시트 브리지`). 문의 시트 브리지와 **별개 프로젝트**로 만듭니다.
2. `Code.gs` 내용을 이 폴더의 `Code.gs` 로 교체합니다.
3. 프로젝트 설정 → **스크립트 속성**에 추가합니다.
   - `BRIDGE_SPREADSHEET_ID` : 정산 시트 주소의 `/d/` 와 `/edit` 사이 값
   - `BRIDGE_SHEET_NAME` (선택): 읽을 탭 이름. 없으면 첫 번째 탭을 읽습니다.
4. 편집기에서 `setupToken` 함수를 **한 번 실행**합니다. 실행 로그에 나온 값이 토큰입니다. 이 값은 채팅이나 저장소에 적지 말고 바로 5번에 넣으세요.
5. **배포 → 새 배포 → 웹 앱**: 실행 계정 `나`, 액세스 권한 `모든 사용자`. 나온 `/exec` 주소를 복사합니다.
6. Vercel 환경변수에 추가하고 다시 배포합니다.
   - `SETTLEMENT_SCRIPT_URL` = 5번의 `/exec` 주소
   - `SETTLEMENT_SCRIPT_TOKEN` = 4번의 토큰
7. 인트라넷에 **관리자 계정**으로 로그인해 `정산` → `정산 시트` 메뉴를 엽니다.

## 코드를 고쳤을 때
같은 배포를 **수정 → 새 버전 → 배포**로 올립니다. "새 배포"를 만들면 주소가 바뀌어 `SETTLEMENT_SCRIPT_URL`도 바꿔야 합니다.

## 안전장치
- 모든 요청은 스크립트 속성 `BRIDGE_TOKEN` 과 같은 토큰이 있어야 합니다.
- 허용하는 동작은 `read` 하나뿐입니다. 다른 동작은 `bad_action` 으로 거절됩니다(자동 시험이 확인합니다).
- 인트라넷 쪽은 **관리자만** 이 데이터를 볼 수 있습니다(로그인 + 관리자 확인).
- 인트라넷 서버는 구글 Apps Script 주소(`script.google.com`)만 호출합니다.

## 시트 형식
첫 번째 줄(또는 맨 위 제목 몇 줄 아래의 첫 헤더 줄)에 `인플루언서명` 과 `결제 여부` 열 제목이 있어야 합니다. 읽는 열: 구분, 광고주, 프로젝트명, 인플루언서명, 인플루언서 비용, 공제 후 금액, 광고주 계약 매출, 업로드 여부, 업로드 URL, 결제 여부, 결제일. 열 제목의 공백은 무시하고 일부 별칭(예: `지급 비용`)도 읽습니다.

시트에 이상한 값(숫자가 아닌 금액, 합계 행, 빈 결제 여부 등)이 있어도 멈추지 않고 읽되, 화면 위쪽의 "시트 데이터 확인 필요"에 무엇이 이상한지 행 번호와 함께 알려 줍니다.
